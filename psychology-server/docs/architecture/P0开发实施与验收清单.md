## 阶段 1　项目基础与 Alembic 迁移框架

| 项 | 内容 |
| --- | --- |
| **前置条件** | v1.2 获批；本地有生产库副本（B1）；Python 环境可安装依赖 |
| **涉及模块** | 数据库基础设施、依赖声明、运维脚本 |
| **预计修改文件** | `app/db/database.py`（保留 `init_db` 但仅供测试/空库）、`requirements.txt`（新增 `alembic`）、新增 `alembic.ini`、`alembic/env.py`、`alembic/script.py.mako`、`alembic/versions/`、`scripts/`（迁移执行与校验脚本）、`.env.example`（迁移相关开关） |
| **实现目标** | ① 引入 Alembic，`env.py` 从 `app.core.config` 读取同一 `DATABASE_URL`；② 对存量库用 `alembic stamp` 建立基线，不重复建表；③ 所有迁移写成可重入（先判断列/索引是否存在）；④ 生产启动不再依赖 `create_all`；⑤ 提供 `upgrade head` / `downgrade -1` / `current` 三条可执行路径 |

| **风险与回滚** | 风险：存量库结构与 ORM 不一致导致 `stamp` 后漂移。回滚：保留迁移前备份；失败即 `downgrade` 到基线并恢复备份；禁止在生产直接调试迁移。 |

| **风险与回滚** | 风险：SQLite 不支持直接删改约束，需重建表。回滚：迁移前备份；重建表迁移必须包在事务内并提供数据校验行数比对。 |

| 项 | 内容 |
| --- | --- |
| **前置条件** | 阶段 2、3 验收通过 |
| **涉及模块** | Timeline API、Schema、Service、模型 |

| **实现目标** | ① `POST /sessions/{sid}/events` 批量写入（1–50000 条）；② 13 类事件白名单；③ 禁止 `answer_value` 及任何可还原答案字段（含 `score`），命中即整批 400/422；④ 三层时间校验：L1 合法性（`relative_seconds < -5.0` → 422 `INVALID_TIMELINE`；重复时间戳 → 422 `DUPLICATE_TIMESTAMP`；明显未来 → 422 `CLOCK_SKEW_TOO_LARGE`）、L2 质量标记（上界 `session_elapsed + 600` 超出 → 200 + `out_of_range`；`[-5,0)` → `pre_anchor`）、L3 不做服务端筛选；⑤ `session_elapsed` 按 `ended_at − started_at`，未结束用 `server_received_at − started_at`；⑥ `server_received_at` 只写接收列 |
| **测试要求** | AC-06/AC-09/AC-10；批量 50000 条性能（< 3s 目标）；上界边界值 `+600` 与 `+600.001`；重复时间戳；`answer_value` 嵌套变体 |
| **验收条件** | 超界数据**全部入库**并带 flag，绝不 422；负值越界整批拒绝、不部分写；导出可见 `quality_info` |
| **风险与回滚** | 风险：批量解析内存峰值。回滚：分块事务 + 限流；校验失败整批回滚，不留半批。 |

| **实现目标** | ① 日志脱敏：`Authorization` / `X-Device-Token` / `X-App-Key` / 答案 / 转写文本一律不落日志（控制台、文件、异常栈、访问日志）；② 查询接口加 `X-Api-Key`（`GET /devices`、`GET /sessions`、结果查询）；③ 设备身份保护 P0 子集（注册快照、变更分级、token 绑定/轮换/撤销、异常审计）；④ A 服务以非 root 运行；⑤ **不做** Nginx、不做 443、不做证书、不改 base URL、不做 301（原安全专项已取消） |
| **测试要求** | AC-27（日志抽样扫描无敏感串）；无/错 `X-Api-Key` → 401；设备侧正常上传不受查询鉴权影响；异常栈不含 token |
| **验收条件** | 日志与异常输出无敏感字段；查询接口必须带 key；P0 接入方式仍为 `http://8.140.240.43:8000`；文档与汇报材料明确标注「P0 明文属阶段性安排」 |
| **风险与回滚** | 风险：查询鉴权导致旧调用方 401。回滚：`X-Api-Key` 支持配置开关与过渡期只告警不拒绝；脱敏过滤器可回退到上一版本但**不建议**。 |

> **已移出本清单的内容**：域名与证书、Nginx 终止 TLS、公网 443、A 监听 `127.0.0.1:8000`、HTTP→HTTPS 301、设备端/Flutter HTTPS 接入、设备 NTP 校时、TLS 证书链与有效期校验、旧端 HTTP 过渡与关闭——相关安全专项已于 2026-11-19 取消，不纳入后续规划；**不得**在本阶段执行。
